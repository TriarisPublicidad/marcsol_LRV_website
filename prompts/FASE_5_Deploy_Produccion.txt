1. **Suite de Pruebas Automatizadas (Pest / PHPUnit):**

   - Redirecciones 301 y refresco de caché ante cambios.
   - Seguridad y roles en el panel administrativo.

2. **Configuración del Servidor Web (Apache / LiteSpeed):**
   - Configura el archivo `public/.htaccess` optimizado para servidores en cPanel/Hostinger:
     * Enrutamiento seguro hacia `/public/index.php`.
     * Activación de compresión GZIP (`mod_deflate`).
     * Cabeceras de expiración y caché de navegador (`mod_expires` / `mod_headers`) para imágenes WebP/SVG y bundles compilados.
     * Bloqueo de archivos sensibles y carpetas ocultas (`.env`, `.git`).
   - Si el hosting no permite modificar el DocumentRoot, suministra un `.htaccess` en la raíz para redirigir el tráfico hacia `/public`.

3. **Compilación de Assets para Producción:**
   - Ejecuta la compilación de assets con Vite: `npm run build`.
   - Asegura que el directorio `public/build/` quede versionado para despliegue directo en servidores sin Node.js.

4. **Pipeline de Optimización en Producción:**
   Verifica y documenta los comandos de consola requeridos en producción:
   - `php artisan storage:link`
   - `php artisan optimize:clear`
   - `php artisan config:cache`
   - `php artisan route:cache`
   - `php artisan view:cache`

5. **Política de Control de Versiones y Respaldo (Git):**
   - Mantén `.env.example` actualizado con los valores predeterminados sin filtrar credenciales privadas.
   - Crea una etiqueta anotada (tag semántico) para fijar el hito de versión estable:
     `git tag -a "v1.0.0-stable" -m "Hito de versión estable"`

     `git branch "backup/YYYY-MM-DD-stable"`
